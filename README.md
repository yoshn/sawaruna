# Sawaruna

**Lock your Mac the moment a human touches it, while AI agents keep working.**

[日本語](README.ja.md)

You hand your Mac to an AI agent and step away. The screen has to stay unlocked so the agent can keep working, but now anyone walking by can use it. Sawaruna watches the mouse and keyboard. Input sent by software, such as an AI agent, is ignored. The moment a real person touches the mouse or keyboard, Sawaruna locks the Mac.

## How it works

1. Press **Control + Option + L**, or click the shield icon in the menu bar and choose **Start guarding**.
2. Keep your hands off for 3 seconds. A chime sounds and guarding begins.
3. If anyone touches the mouse or keyboard, the screen locks right away. Unlock with your usual password or Touch ID.

Sawaruna tells human input from software input by checking which process sent each event. Input from physical devices comes from the system (process ID 0). Input generated by apps comes from those apps. Sawaruna also listens to the physical keyboard directly, because macOS hides key events from other apps while a password field is active. For those, it only checks that a keyboard key was pressed, never which one.

Optional: Sawaruna can take three photos with the Mac's camera at the moment of the touch. This is off by default.

## Requirements

- macOS 13 Ventura or later (Apple silicon or Intel)
- Xcode Command Line Tools, to build from source

## Install (build from source)

```sh
git clone https://github.com/yoshn/sawaruna.git
cd sawaruna
zsh install.command
```

The installer builds the app on your Mac, puts it in `~/Applications/Sawaruna.app`, and opens it. Follow the on-screen guide to grant **Input Monitoring**. You can also download the signed and notarized app from [sawaruna.com](https://sawaruna.com).

To remove it, run `zsh uninstall.command`. Photos taken by Sawaruna stay in `~/Pictures/Sawaruna`.

## Troubleshooting

**Input Monitoring is on, but Sawaruna still says it is not allowed.** This happens when an older copy of Sawaruna (for example, one you built from source) left its entry in the list. Quit Sawaruna, run the command below, open Sawaruna again, and turn on the new entry.

```sh
tccutil reset ListenEvent com.sawaruna.app
```

## Privacy

- Sawaruna never connects to the internet. The source contains no networking code.
- It never uses or records which keys you press. It only uses the fact that something was touched.
- It watches input only from the moment you start guarding (including the 3-second wait) until it locks.
- Photos (if you turn them on) are saved only on your Mac.

See [PRIVACY.md](PRIVACY.md) and [SECURITY.md](SECURITY.md), including what Sawaruna cannot protect against.

## Code signing policy

- **Mac:** release builds are signed with an Apple Developer ID certificate and notarized by Apple. They are built from the source in this repository with [release.command](release.command).
- **Windows:** release builds are made only by [GitHub Actions](.github/workflows/windows.yml) from the source in this repository. They are not code-signed yet. We plan to sign them through the free code signing program of the [SignPath Foundation](https://signpath.org) for open-source projects.
- **Team roles:** committers and reviewers: [Yoshiki Nakamura](https://github.com/yoshn). Approvers: [Yoshiki Nakamura](https://github.com/yoshn).
- Every signing request is approved by hand by an approver. Accounts that can change the source or approve signing use multi-factor authentication.
- **Privacy:** Sawaruna does not send any information to other networked systems. See [PRIVACY.md](PRIVACY.md).
