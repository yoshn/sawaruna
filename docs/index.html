For Macs that run AI agents

Let the AI keep working. Lock the Mac when a person touches it.

Sawaruna watches for real hands on your mouse and keyboard. Input from AI agents passes straight through. The first human touch covers the screen at once and locks your Mac within a second.

Three steps, then walk away

Start an agent, start Sawaruna, step out. Nothing to configure each time.

  1. Start guarding

    Press Control + Option + L, or click the shield in the menu bar.

  2. Take your hands off

    After 3 seconds a chime sounds. Guarding has begun.

  3. Anyone touches it, it locks

    The screen locks right away. Unlock with your password or Touch ID.

How it tells an agent from a person

macOS records which process sent every mouse and keyboard event. Events from real devices come from the system itself, process 0. Events an agent or automation tool creates come from that tool.

Sawaruna lets the second kind through and locks on the first. It also listens to the physical keyboard directly, because macOS hides key events from apps while a password field is open. Either way it checks only that a key was pressed, never which one.

What it never does

  • No internetThe app contains no networking code. Nothing leaves your Mac.
  • No keyloggingIt never uses or records which keys you press.
  • Watches only while guardingFrom the moment you start guarding, including the 3-second wait, until it locks. Idle, it watches nothing.
  • Photos stay with youOptional and off by default: three photos with the Mac’s camera at the moment of a touch, saved only on your Mac.

What it can’t do

  • Hide your screenPeople nearby can still see what is on it.
  • Stop remote controlScreen sharing tools send input like an agent does, so they don’t trigger a lock.
  • Replace a real lockFor anything truly sensitive, press Control + Command + Q.

Questions

Is it free?
Yes. Sawaruna is free and open source under the GPL v3 or later.
Which agents does it work with?
Agents that control your Mac by sending software input events, including computer-use agents that move the mouse and type for you. Agents that only run in the background, like coding agents in a terminal, keep working as usual. Tools that type through a virtual hardware keyboard look like a person and will trigger a lock.
What if it can’t lock?
Sawaruna checks that the screen actually locked. If not, it keeps the screen covered and turns the display off, which locks the Mac when your Lock Screen setting asks for a password immediately. If that fails too, it stops and tells you the Mac is not locked.
Why does it need Input Monitoring?
That permission is how an app can notice the mouse and keyboard at all. Sawaruna uses it only while guarding, and only to see that something was touched.
Can I check the code?
The whole app is one Swift file on GitHub. You can build it yourself with the included install script.
